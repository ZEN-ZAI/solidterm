# 02 — swift-format the whole app in one commit + blame-ignore

Status: ready-for-agent
Blocked by: 01
Spec: ../spec.md (D2)

## Goal

`xcrun swift-format lint --strict --configuration app/.swift-format --recursive app/SolidTerm app/SolidTermTests` reports nothing (excluding `Generated/`), in a commit that contains no semantic change.

## Steps

1. `cd app && xcrun swift-format format -i --configuration .swift-format --recursive SolidTerm SolidTermTests` (skip `SolidTerm/Generated/`; those are regenerated by `build-rust.sh`).
2. Re-run lint; hand-fix what the formatter cannot: 19 `LineLength` (wrap long string literals / comments), `DoNotUseSemicolons` ×4, `OneVariableDeclarationPerLine` ×2, `UseLetInEveryBoundCaseVariable` ×1 if not auto-fixed.
3. Add `.git-blame-ignore-revs` at repo root containing this commit's hash (amend after the first commit or use a second tiny commit) and run `git config blame.ignoreRevsFile .git-blame-ignore-revs` locally. Mention the file in `CONTRIBUTING.md` setup.
4. Confirm `git diff --stat` touches only `.swift` files under `app/` plus the two files above.

## Verify

```
cd app && xcrun swift-format lint --strict --configuration .swift-format --recursive SolidTerm SolidTermTests | grep -v Generated | wc -l   # expect 0
xcodebuild test -scheme SolidTerm -destination 'platform=macOS'   # 446 tests, 0 failures
```
