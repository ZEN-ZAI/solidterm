# Choose a license for SolidTerm

Status: decided 2026-09-06 — applied by `../hygiene-2026-09/issues/20-apply-gpl-3.0-or-later.md`
Origin: hygiene identity grilling, 2026-09-06 (hygiene-2026-09 D13h); license grilling 2026-09-06 (D15)

## Question

The repo has no `LICENSE` file. `README.md` says "None (private development)";
`CONTRIBUTING.md` says all rights reserved until a license is chosen (the deferral used to
point at a design-vault decision that no longer exists). Cargo manifests carry no
`license` field; `scripts/check-license-headers.sh` is a no-op until this is decided.

## Facts (2026-09-06)

- GitHub `ZEN-ZAI/solidterm` is **public**, 0 stars, not a fork, no license detected —
  readable by anyone, usable by no one.
- Every dependency is permissive: MIT / Apache-2.0 / BSD / ISC / Zlib / Unicode / Unlicense
  (one crate offers LGPL as an alternative). `alacritty_terminal` 0.26 is Apache-2.0 only
  and ships `LICENSE-APACHE` (no NOTICE). Apache-2.0 is compatible with GPLv3, not GPLv2.
- `app/SolidTerm/GlyphAtlas.swift:1-6` already attributes the atlas LRU algorithm to
  Alacritty (Apache-2.0) — keep.
- 20 bundled theme palettes come from MIT-licensed projects (Catppuccin, Dracula, Nord,
  Tokyo Night, …) without attribution; the app bundles no third-party license texts.
- `CONTRIBUTING.md:78` already contains a relicense clause ("likely MIT or Apache-2.0").
- 121 source files would carry a header (82 Swift, 21 Rust, 1 Metal, 17 shell).
- Tooling: `cargo-deny 0.19.4` installed; `cargo about` not.

## Decision

**GPL-3.0-or-later for the whole repository** (app, crates, scripts, themes).

The stated intent was "anyone may use and modify it; nobody may take it and sell it."
Permissive licenses (MIT / Apache-2.0) cannot express the second half; source-available
licenses (PolyForm Noncommercial, FSL) express it but are not open source and PolyForm NC
would forbid using the terminal at work. GPL-3.0 is the OSI-approved license that delivers
the intent in practice: resale is legal only with full source under GPL, which makes a
closed resale worthless, and the Mac App Store terms are incompatible with GPL. Cost
accepted: `solidterm-engine` / `solidterm-ffi` can be reused by other projects only under
GPL. Name protection (trademark) is a separate lever from the license.

Sub-decisions:

| | Decision |
|---|---|
| Scope | one license for everything; shell-integration scripts sourced by a user's shell do not make the user's rc files derivative works |
| Headers | SPDX two-liner (`SPDX-License-Identifier: GPL-3.0-or-later` + `Copyright © 2026 Zen Kiattikhunnawong`) on all 121 source files, `Generated/` excluded; `scripts/check-license-headers.sh` enforces in CI; theme TOMLs get a palette attribution line instead |
| Notices | `THIRD_PARTY_NOTICES.md` generated by script from the crates linked into the binary + swift-bridge runtime + palettes; committed, bundled into `SolidTerm.app/Contents/Resources/`, linked from the About panel; CI fails when stale |
| Contributors | inbound = GPL-3.0-or-later plus the existing maintainer relicense clause; no DCO |
| Record | ADR `docs/adr/000N-license-gpl-3.0-or-later.md`; `license = "GPL-3.0-or-later"` in `[workspace.package]`; `publish = false` stays |
| Sequencing | hygiene ticket 20, after 19 and before 17; ticket 18 writes the final license wording into `CONTRIBUTING.md`, `deny.toml`, `check-license-headers.sh` so those files are touched once |

## Rejected

- **MIT / Apache-2.0** — would allow closed resale, contradicting the intent.
- **FSL-1.1-Apache-2.0** — states the no-compete rule literally and converts to Apache after
  two years, but is not OSI open source.
- **PolyForm Noncommercial** — forbids all commercial use, including a developer running
  SolidTerm at their job.
- **Stay unlicensed / go private** — leaves a public repo that grants no rights.
